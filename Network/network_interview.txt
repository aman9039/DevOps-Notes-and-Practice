Q.What is the Internet?
Answer: The Internet is a global network of interconnected computers and devices that communicate with each other using the TCP/IP protocol.

Q.What is a Network?
Answer: A network is a group of devices connected together to share data.
Network = Communication

Q.What is an IP Address?
Answer: IP Address is the unique address of a device in a network.
Like every house has an address, every computer has an IP.
IP = Identity of device

Q.What is MAC Address?
Answer: MAC Address is the physical address of Network Card.

It never changes normally.

Difference

MAC = Hardware Identity

Q. What is Subnet Mask?
Answer: Subnet Mask tells which part is Network and which part is Host.
Subnet = Divide Network

A Subnet Mask is a 32-bit number used to identify:

Network ID (which network the device belongs to)
Host ID (which device within that network)

"Which part of the IP address is the network and which part is the host."

Q. What is Port?
Answer: Port identifies a service running on a server.

IP = House Address
Port = Room Number

Q. what is TCP and UDP explain ?
Answer: 
TCP(Transmission control protocol) = TCP is a connection-oriented and reliable protocol that guarantees data delivery in the correct order.

UDP(User datagram protocol) = UDP is a connectionless protocol that is faster than TCP but does not guarantee delivery.

Why is TCP slower?
"Because TCP waits for acknowledgments, retransmits lost packets, and keeps packets in order."

Why is UDP faster?
"Because UDP sends packets without acknowledgments or retransmissions."

examples of TCP --> "HTTP, HTTPS, SSH, FTP, SMTP, MySQL, PostgreSQL."
examples of UDP --> "DNS, DHCP, VoIP, online gaming, live streaming, NTP."

TCP = Telephone Call ☎️
UDP = Radio Broadcast 📻

Q. What is a reverse proxy?
Answer:
A reverse proxy is a server that sits between clients and backend servers. It receives client requests, forwards them to the appropriate backend server, and returns the response to the client. Reverse proxies are commonly used for security, SSL termination, load balancing, and hiding backend infrastructure.

Forward Proxy  -> Protects Clients
Reverse Proxy -> Protects Servers

User -> Reverse Proxy -> Application
